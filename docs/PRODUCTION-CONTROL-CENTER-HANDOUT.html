Gold & Silver Manufacturing — Floor Command Screen
Client Handout · 1 Page
Same ERP login · Full-screen workspace
Know where every gram is: which batch, which department, who holds it, why it moved, what weight went in/out, and who performed every action — from vault issue to vault return.

Open & Close

  • Open: ERP sidebar → Production
  • Opens full-screen Control Center (no ERP sidebar)
  • Header only: title · LIVE · CLOSE
  • Close: returns to previous ERP screen
  • No second login; session stays active

Metal Flow

VAULT → MELT → CAST → ROLL → BANGLE → STAMP → POLISH → QC → PACK → VAULT
  • Metal leaves vault as a Batch
  • Moves only with a Pass (handover)
  • Work recorded as a Process
  • Checked in QC, then may return to vault

Daily path (simple)

  1. Create Batch
  2. Issue from Vault
  3. Pass → Approve → Issue → Receive
  4. Start / Complete Process
  5. QC → Return to Vault

Safety rules

  • Receive is manual (never auto)
  • Weights not silently edited
  • Corrections = adjustment records
  • Empty screens if no real work
  • ERP inventory stays source of truth
