# Production Control Center — Training Checklist

**Audience:** Client floor teams  
**Goal:** Confident daily use in two short sessions  
**Login:** Same ERP account (no second login)

Print companion handout: [PRODUCTION-CONTROL-CENTER-HANDOUT.html](./PRODUCTION-CONTROL-CENTER-HANDOUT.html) → browser **Print → Save as PDF**.

---

## Before training starts (admin / trainer)

- [ ] Trainee can log into the correct company portal
- [ ] Trainee can see **Production** in the sidebar
- [ ] Open Production once and confirm full-screen opens (no ERP sidebar)
- [ ] Confirm **CLOSE** returns to ERP
- [ ] Decide roles for each person (Manager / Vault / Operator / QC)
- [ ] Have one real or training inventory item ready for vault issue (optional Day 2)

---

## Day 1 — Orientation (Managers + Operators + QC)

**Time:** ~45–60 minutes  
**Focus:** What it is, how to navigate, how to read Live Floor

### 1. Open / Close (everyone) — 5 min

| Step | Done |
|------|------|
| Log into ERP | [ ] |
| Click **Production** in sidebar | [ ] |
| Confirm header shows: PRODUCTION CONTROL CENTER · LIVE · CLOSE | [ ] |
| Confirm there is **no** ERP sidebar / back / breadcrumb | [ ] |
| Click **CLOSE** and return to ERP | [ ] |
| Re-open Production | [ ] |

**Pass criteria:** Person can open and close without help.

---

### 2. Menu tour (everyone) — 15 min

Walk each top menu. Trainee says in one sentence what it is for.

| Menu | Trainee can explain | Done |
|------|---------------------|------|
| **Live Floor** | Whole factory now (default) | [ ] |
| **Overview** | Search metal + dept balance | [ ] |
| **Batches** | Create / list lots | [ ] |
| **Metal Movement** | Permanent move history | [ ] |
| **Passes & Handovers** | Approve / issue / receive | [ ] |
| **Processes** | Start & complete shop work | [ ] |
| **Quality Control** | PASS / FAIL / HOLD / REWORK | [ ] |
| **Machines** | Register + status | [ ] |
| **Alerts** | Problems needing attention | [ ] |
| **Audit Log** | Who did what (managers) | [ ] |

**Pass criteria:** Trainee can find each menu without hunting.

---

### 3. Live Floor reading (everyone) — 15 min

| Skill | Done |
|-------|------|
| Read KPI strip (Active, Metal WIP, Waiting, QC, Hold, Alerts, Machines, Pass) | [ ] |
| Read flow strip Vault → … → Vault | [ ] |
| Read Active Production table columns | [ ] |
| Open a batch detail (if any row exists) OR explain empty state is normal | [ ] |
| Find Metal Custody panel | [ ] |
| Find Attention / Alerts panel | [ ] |
| Find Recent Activity | [ ] |

**Key teaching point:** Empty screens mean no real work yet — the system does **not** invent fake gold weights.

## Day 2 — Hands-on workflow

**Time:** ~60–90 minutes  
**Focus:** Run one complete batch path (happy path)

Use a **training batch** if possible. Do not invent fake balances in live client stock without approval.

### A. Managers / Vault — Create & issue

| Step | Owner | Done |
|------|-------|------|
| Go to **Batches** → Create batch (metal, purity, weight, purpose) | Manager | [ ] |
| Note the batch number (e.g. MG-…) | Everyone | [ ] |
| Issue metal from vault inventory into the batch | Vault / Manager | [ ] |
| Confirm Live Floor shows the batch / Metal WIP changed | Manager | [ ] |

### B. Pass handover — Vault → Melting (or first dept)

| Step | Owner | Done |
|------|-------|------|
| **Passes** → Create pass (from / to / weight / purpose) | Manager / Operator | [ ] |
| **Approve** pass | Manager | [ ] |
| **Issue** pass | Manager / Vault | [ ] |
| Receiving person clicks **Receive** (explicit) | Operator | [ ] |
| Confirm batch department + holder updated | Everyone | [ ] |
| Try Receive again → system should not duplicate | Trainer demo | [ ] |

### C. Process work — Operators

| Step | Owner | Done |
|------|-------|------|
| **Processes** → Start (e.g. Melting) | Operator | [ ] |
| Complete process with output / scrap / loss | Operator | [ ] |
| If variance is large, note Alert / possible HOLD | Manager | [ ] |
| Optional: create next pass to next department and receive | Team | [ ] |

### D. QC — Inspectors

| Step | Owner | Done |
|------|-------|------|
| **Quality Control** → submit result | QC | [ ] |
| Demo FAIL or REWORK once (then PASS) if time allows | QC | [ ] |
| Confirm QC history still visible afterward | Everyone | [ ] |

### E. Close the loop — Vault / Manager

| Step | Owner | Done |
|------|-------|------|
| Return batch to vault (authorized role) | Vault / Manager | [ ] |
| Check **Metal Movement** history exists | Manager | [ ] |
| Check **Audit Log** shows key actions | Manager | [ ] |
| Use **Overview** search by batch number | Everyone | [ ] |
| **CLOSE** Production and reopen ERP | Everyone | [ ] |

## Day 2 role checklists (tear-off style)

### Operator — “I can do this alone”

- [ ] Open Production
- [ ] Find my batch on Live Floor or Batches
- [ ] Receive a pass
- [ ] Start my process
- [ ] Complete process with weights
- [ ] Ask manager if alert/hold appears
- [ ] Close Production

### QC Inspector — “I can do this alone”

- [ ] Open Production
- [ ] Open Quality Control
- [ ] Submit PASS / FAIL / HOLD / REWORK
- [ ] Find inspection in QC history
- [ ] Close Production

### Vault Officer — “I can do this alone”

- [ ] Open Production
- [ ] Support batch issue from vault
- [ ] Help create/issue/receive vault-related passes
- [ ] Return finished/scrap metal to vault when instructed
- [ ] Close Production

### Floor / Production Manager — “I can run the floor”

- [ ] Read Live Floor in under 30 seconds
- [ ] Create batch + approve passes
- [ ] Hold / release when needed
- [ ] Review Alerts and resolve
- [ ] Use Overview search (“Where is my metal?”)
- [ ] Review Audit Log after a shift
- [ ] Train a new operator on Receive + Process only

---

## Common mistakes (teach explicitly)

| Mistake | Correct behavior |
|---------|------------------|
| Assuming metal arrived because pass was issued | Receiver must click **Receive** |
| Editing weight quietly in chat/notes | Use official process complete or weight adjustment (manager) |
| Thinking empty Live Floor is broken | Empty = no active work yet |
| Creating a second receive by double-click | System blocks duplicate receive |
| Expecting Production to replace ERP accounts | Production tracks custody; ERP keeps inventory/books |

## Quick reference — happy path

```text
ERP → Production
  → Batches: Create
  → Issue from Vault
  → Passes: Create → Approve → Issue → Receive
  → Processes: Start → Complete
  → QC: PASS
  → Return to Vault
  → CLOSE → ERP
```
